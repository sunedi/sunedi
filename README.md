## Featured project

### [E-commerce Analytics Warehouse](https://github.com/sunedi/ecommerce-analytics-warehouse)

A SQL Server warehouse and analysis of about 100,000 real orders from Olist, a Brazilian online marketplace.

- **Layered build:** raw → staging → star schema → dashboard tables, rebuilt from the source files with one command
- **Customer location history** (slowly changing dimension, Type 2), so each order is credited to where the customer lived at the time
- **119 automated checks** reconcile every layer back to the source files, to the cent
- **Reconciliation controls** with an exception register that opens and resolves payment mismatches run by run
- **Power BI dashboard** built on the tested tables

**What the data showed:** growth came from more orders (+140%), not bigger baskets. Late deliveries drive 1-star reviews: 70% of orders 8+ days late get one. Only 2% of customers return within six months.

`T-SQL` `window functions` `CTEs` `MERGE` `star schema` `SCD Type 2` `Power BI` `DAX` `data quality`
